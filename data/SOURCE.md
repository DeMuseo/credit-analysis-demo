# Dataset source — Tap4Fun / DataCastle

## Primary (this demo)

| Item | Detail |
|------|--------|
| File | `tap4fun_sample.csv` (100,000 rows) |
| Schema | Official DataCastle 2018 **游戏玩家付费金额预测** train fields (subset) |
| Game | Tap4Fun 《野蛮时代》 / Brutal Age (China F2P SLG) |
| Target task | From first **7 days** of play, predict **45-day** spend `prediction_pay_price` |
| Full train size | ~2,288,007 labeled rows (~2% payers) |

### Columns kept in the sample

`user_id`, `register_time`, `wood_add_value`, `ivory_add_value`, `bd_stronghold_level`,  
`pvp_battle_count`, `pvp_lanch_count`, `pvp_win_count`,  
`pve_battle_count`, `pve_lanch_count`, `pve_win_count`,  
`avg_online_minutes`, `pay_price`, `pay_count`, `prediction_pay_price`

**This file** is a **schema-faithful stratified demo sample** generated by `scripts/build_tap4fun_sample.py`, calibrated to published competition aggregates from public EDA write-ups (≈2% 付费率, stronghold×PUR curve, payer vs non-payer online-time contrast). Suitable for Gradio portfolio load; replace with a real stratified slice of `tap_fun_train.csv` when a reachable mirror is available (same column names).

No personal names in the data or UI.
